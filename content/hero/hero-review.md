## story | Five problems, one PR

A contractor opens "Add report search (generated with AI, tests pass)". It's short. It also contains, in about twenty lines, a problem from almost every realm you've completed. Rumana: "This is the review I'd want from a teammate. Find all of them, say why each matters, and give a clear verdict."

## model | Review with the whole map

- **Secrets**: anything key-shaped in code.
- **Access control**: ownership checks on every object; permissions on every route.
- **Injection**: SQL built from strings.
- **Scale**: lists without limits.
- **Tests**: what was *removed* matters as much as what was added.
- A verdict: approve, or request changes with blocking items listed.
